# Notes: Types of Machine Learning

This topic covers the main types of Machine Learning and their respective sub-types.

## 1. Supervised Learning
* **Regression**: Used for predicting continuous values or numerical outputs.
* **Classification**: Used for dividing data into discrete categories or classes.

## 2. Unsupervised Learning
* **Clustering**: Grouping similar data points together.
* **Dimensionality Reduction**: Reducing the number of features/dimensions in the data without losing essential information.
* **Anomaly Detection**: Identifying unusual or abnormal patterns (outliers) in the data.
* **Association**: Finding rules that explain relationships between variables in large datasets.

## 3. Semi-Supervised Learning
* Uses a combination of both labeled and unlabeled data for training (combines elements of supervised and unsupervised learning).

## 4. Reinforcement Learning
* An agent learns to make decisions by interacting with an environment through trial and error, using rewards and penalties.
