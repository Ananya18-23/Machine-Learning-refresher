# Module: Data Gathering and Understanding
---

## Day 15: Working with CSV Files
* **Overview:** Learning how to load, inspect, and handle comma-separated values (CSV) datasets using Pandas.
* **Key Topics:** `pd.read_csv()`, handling missing headers, parsing dates, and handling large files in chunks.

## Day 16: Working with JSON and SQL
* **Overview:** Extracting and structuring data from semi-structured JSON formats and relational databases using SQL queries.
* **Key Topics:** Flattening JSON data, connecting SQL databases with Python, and executing basic queries for ML datasets.

## Day 17: Fetching Data From an API
* **Overview:** Pulling live or dynamic data from web services using REST APIs.
* **Key Topics:** Using the `requests` library, handling JSON responses, authentication keys/tokens, and status codes.

## Day 18: Fetching Data Using Web Scraping
* **Overview:** Extracting data directly from websites when an API is not available.
* **Key Topics:** Using BeautifulSoup and Selenium, parsing HTML tags, handling pagination, and scraping dynamic web pages.
